# Воспроизведение исследования

Это команды для разработчика после первого запуска приложения. Для fish активация окружения не нужна:

```fish
.venv/bin/python -m tools.calibrate_ranking
.venv/bin/python -m tools.calibrate
.venv/bin/python -m tools.evaluate
.venv/bin/python -m tools.analyze
```

Каждый метод оценивается в отдельном процессе: rule baseline, BoW stem/lemma, TF-IDF stem/lemma, BM25, E5, hybrid RRF, hybrid + cross-encoder, verified_hybrid с приоритетом источника и исходного ранга. Индекс включает вопросы, ответы и поисковые варианты. FAQ и варианты не формируются из тестовых запросов. Запросы и разметка составлены с помощью ИИ, не являются независимой человеческой оценкой.

`dev`: настройка порога отказа. `test`: оценка после фиксации порога. В обоих наборах 48 вопросов с ожидаемым источником, 12 без ответа и 1 уточнение. Метрики поиска считаются только по вопросам с релевантным документом; отказы оцениваются отдельно. Прогоны сохраняются с UUID и fingerprint. Не переименовывайте повторно использованную при исправлениях выборку в «независимую».

P@1 — релевантность первого результата. P@3 — число размеченных релевантных результатов / 3 (при одной релевантной карточке максимум 1/3). Hit@3 — есть ли такой результат в тройке. MRR@5 — обратная позиция первого релевантного результата в первых пяти. Метки неполны: другие корректные источники могут считаться ошибками. Для диалога дополнительно проверяются отказ, уточнение и выбранные источники; это не автоматическая гарантия истинности каждого утверждения.

`peak_rss_mb` — Linux ru_maxrss / 1024, пик памяти отдельного процесса, включая загрузку библиотек и моделей. Время запроса включает предобработку и ранжирование; время построения индекса сохраняется отдельно. Повторные прогоны могут использовать кеш эмбеддингов. Модель не дообучается на этом корпусе.

Проверки:

```fish
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Диагностика без подключения Telegram: `python3 start.py --site-only`. Консольное меню: `.venv/bin/python main.py`. Эти режимы не заменяют основной запуск из README.
