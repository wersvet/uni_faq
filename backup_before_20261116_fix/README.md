# AITU Campus Answers — University FAQ Retrieval Chatbot

Новый самостоятельный проект по дисциплине **Programming for Data Analysis and Database**, тема 18. Полностью локальный поиск: SQLite + BM25 + многоязычная E5 + cross-encoder. Платные API не нужны. Бот извлекает ответы из базы и показывает источники; он не является официальным сервисом AITU.

## Запуск всего приложения из fish

1. Распакуйте архив в отдельную папку. Откройте терминал **в папке, где лежит этот README и start.py**.
2. На Fedora один раз установите Python:

```fish
sudo dnf install -y python3 python3-pip
```

3. Если старая версия Telegram-бота работает с тем же токеном, остановите её через **Ctrl+C**. Затем выполните:

```fish
python3 start.py
```

4. При первом запуске вставьте токен существующего бота из BotFather и нажмите Enter. Символы при вводе скрыты. Токен сохраняется только в `.env`; не отправляйте этот файл другим людям. Ранее опубликованный токен нужно заменить через BotFather.
5. Дождитесь **«5/5 Готово»**. Откройте **http://127.0.0.1:8502** и ссылку Telegram, напечатанную программой. Сайт и бот используют один сервер поиска и одну SQLite-базу.
6. Оставьте терминал открытым. Остановка — **Ctrl+C**. Следующий запуск: та же команда `python3 start.py`. База и настройки сохраняются.

Программа сама создаёт `.venv`, устанавливает библиотеки и загружает модели. При первом запуске нужен интернет и несколько гигабайт свободного места. Для CPU рекомендуется 8 ГБ RAM или больше; фактические измерения есть в отчёте. Проверяемая среда — Linux / Python 3.14. PostgreSQL, Docker, платные ключи ИИ и ручная активация окружения не нужны. Интернет требуется для Telegram; после загрузки моделей сам поиск может работать автономно (`FAQ_OFFLINE=1` в `.env`).

Попробуйте: «Сколько стоит обучение в айту?» → «Бакалавриат»; «В общаге есть интернет?»; «Как записаться на АЕТ?»; «Какие документы нужны для обмена?». `/reset` в Telegram или кнопка на сайте начинает новый разговор.

## Если запуск остановился

- **Порт занят**: остановите предыдущий запуск. При необходимости поменяйте `FAQ_WEB_PORT` и `FAQ_API_PORT` в `.env`.
- **Telegram Conflict**: с этим токеном работает ещё одна копия. Остановите её; не запускайте старый и новый проекты одновременно с одним ботом.
- **Не удалось подключиться к Telegram**: проверьте интернет и токен. Очистите `TELEGRAM_BOT_TOKEN` в `.env`, чтобы ввести заново.
- **Модель не загружается**: первый запуск требует доступа к Hugging Face. Проверьте, что `FAQ_OFFLINE=0`, и посмотрите `artifacts/logs/api.log`.
- **Ошибка приложения**: файлы `artifacts/logs/api.log`, `site.log`, `telegram.log`. Не публикуйте `.env` и секреты.

## Данные и ограничения

608 исходных строк AITUAdmissionsGuideDataset сохранены в `data/raw.parquet`, 556 уникальных вопросов с выбранной версией ответа — в `data/original_faq.parquet`. Вместе с 48 официальными дополнениями база содержит 604 карточки. Ещё 96 поисковых формулировок хранятся как псевдонимы карточек, а не как новые факты. Все 604 записи доступны на сайте и участвуют в поиске; исходные сведения отмечены как не проверенные на актуальность. У 18 исходных вопросов обнаружены разные версии ответа: они сохранены в conflicting_answers.json, и бот отказывается выдавать произвольно выбранную версию.

Бот учитывает уровень обучения и контекст коротких продолжений, но не имеет доступа к личным кабинетам, актуальной занятости комнат и будущим тарифам. Ответы составляются из найденных текстов, без генеративной LLM. Показатель сходства не является вероятностью правильного ответа. Человеческая проверка фактов и тестовой разметки остаётся необходимой.
